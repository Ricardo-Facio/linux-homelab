# Linux Homelab

> Laboratório pessoal desenvolvido para estudos práticos de Linux, Redes de Computadores e Infraestrutura de TI.

## 📖 Sobre o projeto

Este repositório documenta minha jornada de aprendizado em Infraestrutura de TI.

O objetivo é registrar, de forma organizada, todos os laboratórios, configurações, testes e conceitos estudados durante minha formação, utilizando máquinas virtuais e ferramentas amplamente empregadas no mercado.

Todo o conteúdo foi desenvolvido como parte dos meus estudos, buscando consolidar conhecimentos e construir um portfólio técnico.

---

## 🎯 Objetivos

- Aprender Linux na prática;
- Estudar Redes de Computadores;
- Compreender protocolos e serviços de rede;
- Administrar servidores Linux;
- Desenvolver um laboratório (Homelab);
- Documentar cada etapa do aprendizado;
- Construir um portfólio para oportunidades em Infraestrutura de TI.

---

## 🛠️ Ambiente de estudos

- Sistema Operacional Host: Windows 11
- Virtualizador: Oracle VirtualBox
- Sistema Operacional Guest: Ubuntu Desktop LTS
- Terminal: Bash
